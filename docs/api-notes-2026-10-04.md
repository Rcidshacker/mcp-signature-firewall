## Lightning "thinks" by default
- With `max_tokens=64` and JSON mode, Lightning spent the whole budget on a visible reasoning preamble
  (`finish_reason=length`, content began "Here's a thinking process"). JSON mode did not stop it.
- With `max_tokens=512` it answered `{"ok": true}` correctly but took 5 to 7 s and about 250 tokens.
- `chat_template_kwargs: {"enable_thinking": false}` fixed it: 5 completion tokens, 0.56 s, clean JSON.
- `reasoning_effort: "low"` did nothing useful (truncated, 18.9 s). `nvext.enable_thinking` is rejected with HTTP 400.
- Consequence: the measured system includes this request option, carried in `LLM_EXTRA_BODY` and recorded in
  `protocol.toml` before the frozen run. Config can never override `model`, `messages` or `temperature` (tested).
